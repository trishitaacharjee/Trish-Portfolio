# Trishita Acharjee — Portfolio

This is a single self-contained HTML file (`index.html`) — no build steps, no dependencies to install.

## Open it locally
Just double-click `index.html`, or open the folder in VS Code and use the "Live Server" extension (right-click index.html → "Open with Live Server") for the best local preview.

## Publish it for free (GitHub Pages)
1. Create a new GitHub repo named exactly: `yourusername.github.io`
2. Upload `index.html` to the repo root (keep the filename as `index.html`)
3. Commit the changes
4. Go to Settings → Pages → set Source to the `main` branch, `/ (root)` folder → Save
5. Wait 1-2 minutes, then your site is live at: `https://yourusername.github.io`

## Alternative: Netlify Drop
Go to https://app.netlify.com/drop and drag the `index.html` file onto the page — you'll get an instant live link, no account needed for a quick share.

## Making edits later
All the HTML, CSS, and JavaScript live in this one file. Colors are defined as CSS variables near the top of the `<style>` tag — change those to restyle the whole site at once.
